## 🧭 About me

- 🔭 I like taking dense, academic subjects and building **explorable explanations** around them — interfaces that let you poke at the data instead of just reading about it.
- 🧬 Recurring obsessions: **historical linguistics**, **ancient DNA & population genetics**, **time-series / chaos**, **LLM agents**, and **data visualization**.
- 🛠️ I ship full-stack: **TypeScript / React / Next.js** on the front, **Python** for data & ML, deployed on **Vercel** and **GitHub Pages**.
- 💬 Ask me about Proto-Indo-European, deck.gl maps, reservoir computing, or wiring Claude Code into real workflows.
