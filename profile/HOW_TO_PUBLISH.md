# How to publish this as your GitHub profile

GitHub shows a special README at the top of your profile page when you have a
**repository named exactly after your username** containing a `README.md`.

## Steps (2 minutes)

1. Go to **https://github.com/new**
2. **Repository name:** `Sakshyam-Patro` (must match your username exactly — GitHub will show a "✨ special repository" hint)
3. Set it to **Public**, check **"Add a README file"**, click **Create repository**
4. Open the new repo's `README.md` → click the pencil ✏️ to edit
5. Delete the contents and paste in everything from [`profile/README.md`](./README.md)
6. **Commit changes**

Your profile at https://github.com/Sakshyam-Patro will now show the new README.

## Notes

- The stats cards (`github-readme-stats`, streak stats) render automatically once
  the README is live — no setup needed.
- Want a different color theme? Replace `theme=tokyonight` in the image URLs with
  another (e.g. `radical`, `dracula`, `gruvbox`, `vue-dark`).
- This file and `README.md` live under `profile/` only as a staging area — they
  don't affect the Indo-European Explorer app.
